## PHASE 1: CRITICAL Security Fixes (Must fix before any deployment)

### 1.1 — Hardcoded Cryptographic Secrets (Payment Forgery Risk)
- **wallet_callback.go:39** — `sandbox_salt_123` fallback for HMAC signatures → `panic()` if env missing
- **cod_handler.go:167** — `default_salt_2026` fallback for payment deep-links → `panic()` if env missing
- **debezium/omnigo-postgres-connector.json:8** — hardcoded DB password in git → use env var substitution
- **docker-compose.yml:6-8** — hardcoded `POSTGRES_PASSWORD` and `NEO4J_AUTH` → use `${VAR}` from .env

### 1.2 — Missing Authentication on Critical Endpoints
- **product_handler.go:89-93** — `/internal/products/reserve` and `/release` publicly accessible → add `InternalOnlyMiddleware`
- **All order/payment/wallet/ledger routes** — no JWT middleware → add auth to every non-public route
- **WebSocket gateway** (`/ws`) — no JWT validation → add auth middleware
- **Vendor wallet/payout endpoints** — financial data exposed → add vendor JWT check

### 1.3 — Flutter JWT Security
- **session_registry.dart:85-86** — JWT stored in plaintext SharedPreferences → migrate to `flutter_secure_storage`
- **main.dart:174-178** — `/admin-surveillance` route has no auth guard → add `isLoggedIn && role == 'admin'`

### 1.4 — Go Version Mismatch
- **Dockerfile:6** — `golang:1.26-alpine` doesn't exist → change to `golang:1.23-alpine`
- **go.mod:3** — `go 1.26.5` invalid → change to `go 1.23`
- **ci.yml:23** — CI uses Go 1.22 → align all to one version

### 1.5 — CORS Wildcard + Credentials
- **cors.go:16-17** — defaults to `*` origin with `Allow-Credentials: true` → refuse start if not configured in production
