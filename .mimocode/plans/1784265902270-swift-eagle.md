## Phase 3: Full Docker Containerization

### 3A. Shared Go Multi-Stage Dockerfile (REWRITE)
Replace current `backend/go-services/Dockerfile` with proper multi-stage:
```dockerfile
# Stage 1: Build
FROM golang:1.22-alpine AS builder
WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download
COPY . .
ARG SERVICE
RUN CGO_ENABLED=0 go build -o /service ./cmd/${SERVICE}

# Stage 2: Runtime
FROM alpine:3.19
RUN apk add --no-cache ca-certificates tzdata
COPY --from=builder /service /service
EXPOSE 8080
CMD ["/service"]
```

## Phase 4: Environment & Security Hardening

### 4A. All Services Require env vars (NO fallbacks)
Every service panics on startup if critical env vars are missing:
- `JWT_SECRET_KEY` (auth, admin, gateway)
- `DB_WRITER_DSN` / `DB_READER_DSN` (all Go services)
- `REDIS_ADDRS` (all Go services)
- `KAFKA_BROKERS` (all services that use Kafka)
- `OSRM_URL` (delivery-gig-service only)
- `NEO4J_URI`, `NEO4J_USER`, `NEO4J_PASSWORD` (admin, graph-sync)
