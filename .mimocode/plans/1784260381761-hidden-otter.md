## 1. Project Overview

**OMNIGO** is an enterprise-grade Super App combining **E-Commerce**, **Delivery/Gig**, and **Ride-Hailing** into a single platform.

| Component | Tech Stack |
|-----------|-----------|
| Backend | Go (11 services), Rust (2 services), Node.js (2 workers), Python (AI engine) |
| Frontend | Flutter mobile app (26 Dart files, 5 feature modules) |
| Database | PostgreSQL 15 + Redis 7 Cluster + Neo4j 5.9 |
| Event Bus | Apache Kafka (KRaft mode) + Debezium CDC |
| Routing | OSRM (Open Source Routing Machine) |
| Infrastructure | Docker Compose (12 services) |
| Payments | Stripe (Intl) + PayFast (PK) + JazzCash + EasyPaisa |

## 5. .gitignore Assessment

### What's Covered ✅
- `.env`, IDE files (`.idea/`, `.vscode/`)
- Go binaries (7 services + `cmd/*/` patterns)
- Rust `target/`, `Cargo.lock`
- Node `node_modules/`
- Python `__pycache__/`, `venv/`, `.pytest_cache/`
- Flutter `.dart_tool/`, `build/`, `.flutter-plugins*`

### What's Missing ❌
| Missing Pattern | Risk |
|----------------|------|
| `uploads/` directory | KYC documents could be committed |
| `secrets/` directory | Service account JSON could be committed |
| `*.pem`, `*.key` | Private keys could be committed |
| `*.env.*` (e.g., `.env.local`, `.env.production`) | Env variants could leak |
| `*.pbf` (OSRM map files) | Large binary files |
| `Cargo.lock` is gitignored but may be needed for reproducible builds | — |
| `backend/go-services/bin/payment-orchestrator` was already committed | Needs history rewrite |

### Recommendation
Add these to `.gitignore`:
```
uploads/
secrets/
*.pem
*.key
*.env.*
*.pbf
```

### Production Issues
1. **No health checks** — Services may receive traffic before being ready
2. **No resource limits** — A single service can OOM the entire host
3. **No restart policies on init containers** — `redis-cluster-init` could fail silently
4. **Credentials in compose file** — `omnigo_password` hardcoded (should use Docker secrets)
5. **No SSL/TLS** — All internal communication is plaintext
6. **No log rotation** — Docker logs will grow unbounded
7. **OSRM requires manual map download** — ~80GB for world, ~9GB for Pakistan
8. **Missing Python AI service** in docker-compose — not included in production stack
